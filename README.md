# ComfyUI-AllBuy_PromptLibrary

ComfyUI 提示词与素材管理全家桶：7 个配套节点，覆盖**提示词库勾选合并、随机抽卡、批量选图映射、图/音/视频素材加载、LoRA 堆栈、A/B 图像对比、大段文本编辑**。全部节点使用统一的自绘面板，支持执行锁定、旁路变暗、调色隔离。

## 节点总览

| 节点 | 输出 | 用途 |
|---|---|---|
| **AllBuy-提示词库** | 正/负提示词 | 把提示词存为卡片，勾选即生效，多组按顺序合并输出 |
| **AllBuy-随机抽卡** | 正/负提示词 | 从库随机抽 N 张合并，seed 可复现，适合找组合灵感 |
| **AllBuy-批量选图** | 图片 / 正/负提示词 / 映射 JSON | 图片 ↔ 提示词组双向映射，输出图片 batch 与对应提示词 |
| **AllBuy-素材加载（图/音/视频）** | 图片 / 遮罩 / 视频帧 / 视频音频 / 帧率 / 帧计数 / 视频信息 / 音频 | 拖入即持久化的素材库：图片裁剪与遮罩编辑、视频选区抽帧、音频波形裁剪 |
| **AllBuy-LoRA 堆栈** | 模型 / CLIP / VAE / 触发词 | 一个节点完成底模加载（Checkpoint/UNET/GGUF）+ 多 LoRA 堆栈 |
| **AllBuy-A/B 图像对比** | 图片 A / 图片 B | 拖分割线对比两图，批量输入可翻页，选中侧直接输出 |
| **AllBuy-文本框** | 提示词 / 提示词行（列表） | 大段提示词编辑：替换表、去空行、撤销重做、与提示词库互转入库 |

## 安装

方式一：克隆到 ComfyUI 的 `custom_nodes/` 目录后重启：

```
ComfyUI/custom_nodes/ComfyUI-AllBuy_PromptLibrary/
```

方式二：ComfyUI-Manager → Install via Git URL 填入本仓库地址。

## 快速上手

1. 双击画布，搜索节点中文名（如「提示词库」「LoRA 堆栈」）添加节点。
2. **提示词库**：点「＋ 新建提示词组」录入内容 → 勾选卡片即生效，拖 ⋮⋮ 调整合并顺序（列表/卡片实时让位，按占位框放到目标组前后；边缘自动滚动）→ 正/负提示词接到文本编码节点。
3. **素材加载**：拖文件进面板（或 Ctrl+V）即入库 `input/allbuy_media/`；图片可多选排 batch，视频/音频在 ⚙ 里选区。
4. **LoRA 堆栈**：选底模类型与模型，按需选择顶部的 CLIP 模型、CLIP 类型与 VAE → 添加 LoRA 行，选文件、调权重、填触发词 → 「模型/CLIP/VAE」三口接下游。

## 全屏资源管理面板

刷新 ComfyUI 后，右下角会出现「资源管理」小浮窗。点击打开全屏面板，点击右上角 × 或按 Esc 收起。浮窗可拖动，位置、上次使用的库及卡片/列表/瀑布流视图保存在当前浏览器。

- **提示词组**：切换库、搜索内容、按分类/标签/收藏筛选，创建/重命名/删除用户库，编辑/复制提示词组、批量分类/标签/删除，以及导入导出 JSON。内置库可浏览和应用，需另存为用户库后编辑。
- **LoRA 模型**：读取 ComfyUI 的真实模型列表，按文件夹、自定义分组、标签和收藏浏览；支持批量标签/分组管理。在详情中设置本次应用的权重及激活提示词，保存为组合即可持久保留这些参数。
- **LoRA 组合**：创建、编辑、重命名、删除及导入导出共享组合，保留模型顺序、启用状态、权重范围及激活提示词。允许保存尚未安装的模型，应用前会检查本地模型是否存在。
- **应用到工作流**：勾选资源，选择已有节点或「新建节点」，点击「添加到工作流」。已有 LoRA 节点追加时跳过重复模型并保留原参数；提示词组应用到同库节点时追加勾选，选择另一库时切换库并使用新选择。修改后仍需在 ComfyUI 中保存工作流。

面板直接使用现有用户库、`lora_groups.json`、`lora_catalog.json` 与 `lora_presets.json`，和节点同步。搜索后「全选」针对当前结果，筛选外的已选项会在底栏标明；长列表分批显示，避免一次挂载大量卡片。面板不下载或删除 LoRA 模型文件。

**LoRA 图片/视频预览**：自动读取模型同目录的同名媒体，如 `model.png`、`model.preview.jpg`、`model.mp4`、`model.preview.webm`，也兼容 `model.safetensors.preview.png` 和 `model.preview.0.jpg`。图片和视频可以同时保存，存在视频时优先预览视频。卡片双击放大预览，视频按钮打开播放器；悬停视频卡片时默认静音，可开启声音，移开停止。大预览支持平移缩放、适应窗口或显示原始尺寸，Esc 先关闭预览再关闭主面板。

详情区可「选择图片…」「选择视频…」上传自定义预览，或用「自定义路径」绑定运行 ComfyUI 的电脑上的绝对路径。自定义项优先于同目录文件；「恢复同目录」解除自定义绑定，保留所有原文件。绑定记录保存在 `ComfyUI/user/allbuy_promptlibrary/lora_previews.json`，上传预览复用 `input/allbuy_media/`；预览图片和视频首帧按需生成，不另存副本。浏览器能否播放视频取决于编码，建议 MP4（H.264）或 WebM。

底部工具区的「界面」滑条调整内容区尺寸（80%–140%），「字体」调整字号（11–20px），即时生效并在当前浏览器保留。滑条区域不随内容区缩放，连续拖动时保持鼠标与滑轨的位置关系；「重置」恢复默认尺寸。管理面板复用原节点的颜色、字体、按钮及输入框样式。更新后强制刷新浏览器以加载新版前端；首次启用新增接口时需重启 ComfyUI。

**右键与下拉框**：提示词卡片、LoRA 卡片、组合卡片和堆栈条目均有右键菜单，可快速预览、收藏、编辑、整理或应用；右键空白资源区可全选、切换视图、刷新，右键小浮窗可恢复位置。卡片收藏改为标题旁的书签按钮。管理面板的下拉框支持搜索、上下键选择、Enter 确认、Esc 收起，选项列表与原插件的深/浅主题配色一致；原节点中的原生下拉框也统一适配选项颜色。标签管理改为可搜索的列表，直接新建、重命名或删除，并显示关联模型数量。

**瀑布流**：点击视图切换区的第三个按钮，预览按图片或视频首帧的原始比例排列，自动填补列之间的空隙；图片加载、窗口变化或字号调整后重新排布。双击放大、视频悬停和多选操作与卡片视图一致。

**预览交互**：LoRA 卡片、右侧预览区和放大窗口均可拖入图片或视频替换素材；存在视频时优先显示视频与其首帧，隐藏图片预览。视频卡片悬停播放，左下角可切换静音或有声；移开后暂停。放大窗口支持拖动平移、鼠标滚轮和加减按钮缩放，也可恢复适应窗口或原始尺寸；视频底部播放控件仍可操作。点击弹窗空白区域或按 Esc 关闭。界面与字体滑条收进底部工具区，拖动时保持固定尺寸。卡片、列表与瀑布流切换复用现有媒体和已读取的尺寸，不再重新载入整批卡片；轻量过渡遵循系统的减少动态效果设置。

导航顺序为「提示词组 → LoRA 模型 → LoRA 堆栈 → LoRA 组合」。堆栈条目显示模型标签，可逐项或批量编辑，也可打开标签管理；标签保存到共享模型目录，立即供其他节点使用，堆栈参数仍需点击应用。

**LoRA 堆栈页签**：左侧列出当前工作流中的堆栈，支持载入已有节点或建立新堆栈草稿。可编辑节点名称、底模类型和文件、CLIP/VAE，以及 LoRA 模型、顺序、启用状态、权重范围和激活提示词；条目右键支持复制、移动和移除。点击「应用到节点」或「创建堆栈节点」才写入工作流，空列表也可应用。参数无效时保留原节点；若节点面板已修改，会提示是否覆盖。草稿还可保存为共享组合，关闭面板前有未应用修改会提示。LoRA 或组合卡片右键的「加入堆栈草稿」可将选中内容追加到此页签，跳过重复模型。应用后仍需保存 ComfyUI 工作流。

## 提示词库核心机制

以下机制适用于提示词库 / 随机抽卡 / 批量选图 / 文本框插入。

**三种库来源**

- 📦 内置库（插件自带示例，只读）
- 🗂 用户库（`ComfyUI/user/allbuy_promptlibrary/`，全局共享，可增删改）
- 📎 内嵌库（JSON 导入，数据随工作流保存，便于分发）

用户库可在库下拉菜单的「操作 → 重命名当前用户库…」修改名称。重命名后库菜单即时更新，当前勾选和排序保留；文件定位保持不变，已保存工作流和其他节点仍能读取。

提示词库和随机抽卡的库菜单支持名称搜索、常用库置顶及最近使用（最多显示 5 个，自动去重）。点击库右侧的 ☆ / ★ 设置或取消常用；搜索框和管理操作固定显示，库列表内部滚动。常用和最近使用保存在当前浏览器，刷新后保留，两种节点共用。

**合并规则**

1. 勾选卡片按已选顺序排列；
2. 每段拼成 `prefix + 正文 + suffix`，权重 ≠ 1 时包裹 `(text:w)`；
3. 用分隔符连接（逗号+空格 / 换行 / 句号 / 分号 / 自定义）；
4. 前置文本 + 合并结果 + 后置文本；
5. 负向提示词走同样流程（不附加前置/后置）。

**通配符 `{a|b|c}`**

卡片正文 / 前后缀 / 前置后置文本均支持，每次执行随机选一项，支持嵌套（如 `{small {red|blue}|big}`）。主节点每次出队重新抽取；需要可复现结果用**随机抽卡**（seed 固定 = 结果固定），或 footer 🎲 固定种子。

**库文件格式**（用户库 JSON，可手编，保存时自动 `.backup`）

```json
{
  "version": 1,
  "name": "我的库",
  "groups": [
    {
      "id": "g-xxxx",
      "name": "电影感慢推镜头",
      "category": "镜头运动",
      "positive": "Cinematic slow dolly-in, 35mm anamorphic lens ...",
      "negative": "shaky cam, fast cuts ...",
      "note": "备注",
      "color": "#4A90D9",
      "weight": 1.0,
      "prefix": "",
      "suffix": "",
      "tags": ["电影感", "推镜"],
      "cover": ""
    }
  ]
}
```

## 各节点要点

**素材加载**：四种入料（拖入 / 文件选择 / 文件夹 / Ctrl+V），持久化到 `input/allbuy_media/`；图片/音频/视频三 Tab 浏览。图片 ⚙ 框选裁剪 + 画笔遮罩（遮罩口与 batch 逐张对齐）；视频 ⚙ 选区抽帧（目标帧率/帧上限实时预览）；音频 ⚙ 波形选区裁剪；支持导出 PNG / MP4 / WAV。

**素材统一托管**：新导入的素材和提示词组预览共用 `input/allbuy_media/` 下的一份原文件，使用完整 SHA-256 内容 ID；同内容换名、重复导入或跨节点使用均复用，内容不同的同名文件分别保存。原文件名留作展示与备注，导入后移动或删除外部原文件不影响使用。图片缩略图和视频首帧按需生成并缓存在内存中，不另存预览副本。上传以临时文件流式接收，完成后原子发布，失败不留半成品。

旧版 `input/allbuy_covers/` 封面及原素材清单继续可读。替换、移除预览或清空素材节点只解除引用，新托管文件不会自动删除，以保留已保存工作流的引用；已有旧文件不自动迁移或删除。备份时需同时保留库、工作流和 `input/allbuy_media/`（有旧预览时也需保留 `input/allbuy_covers/`）。

**LoRA 堆栈**：Checkpoint / UNET / GGUF 三种底模（GGUF 需装 ComfyUI-GGUF，带反量化等高级参数）。每行 LoRA 可手填权重、调范围、微调钮、触发词（底栏实时汇总一键复制）、启用开关、拖拽避让排序，滑条步进 0.05。点击「添加 LoRA」选择文件，右键选择添加整组；选择后、再次点击按钮或点击别处收起选择器。支持自定义分组（我的收藏 ★ 等，分组管理与整组导入导出），R 刷新同步更新选项。点击「清空」后可在 10 秒内撤销，撤销保留清空后新添加的条目。「列表储存」可命名保存、使用（替换当前列表）、追加、覆盖、重命名和删除列表，保留顺序、权重、范围、启用状态和触发词；点击保存项的「编辑」可直接选择或输入 LoRA 模型、修改参数与激活提示词，支持增删和上下移动条目，保存回原列表，取消或按 Esc 返回时放弃本次修改。数据保存在 `ComfyUI/user/allbuy_promptlibrary/lora_presets.json`，跨节点和工作流复用。堆栈预设仍可导入导出 JSON。

**LoRA 分组选择与编辑空间**：添加弹窗中的分组和未分组区域均可点击标题折叠，分组下拉框可限定候选范围，并与搜索、标签筛选同时使用。分组筛选和折叠状态随节点保存。「编辑列表」弹窗扩大至接近窗口大小，条目区域独立滚动，保存、取消等操作始终保留在底部。

**LoRA 的 CLIP / VAE**：节点顶部预留区域可独立选择 CLIP 模型、CLIP 类型和 VAE，选项与 ComfyUI 原生加载器一致。选「默认 / 底模自带」时沿用 Checkpoint 的对应输出，UNET / GGUF 则不额外加载；选择具体文件会通过原生加载器提供对应输出。新增参数追加在原有参数后，兼容旧工作流。更新后须重启 ComfyUI 并刷新浏览器。

**A/B 图像对比**：拖分割线对比，悬停跟随模式可免按住；批量输入按页翻看（单侧批量自动前后帧配对）；「自动输出」关闭时可手动选侧再输出。

**批量选图**：文件夹/图片多选映射到提示词组，挂组管理；输出图片 batch + 按图合并的提示词 + 映射 JSON，适合 LoRA 训练集或成套出图。

**文本框**：大段文本编辑（宽软换行、行数统计）；每行 `旧=新` 的替换表按序应用；去空行开关；@素材名 转为 image1..10 文本标记；入库/从库插入（记住上次库与组）；撤销/重做/历史快照。

**LoRA 多选**：主列表及保存列表编辑器均可点击「多选」，勾选条目后批量删除、统一修改权重、收藏或取消收藏。Shift 点击复选框可连续选择；「全选」只选择当前筛选结果，筛选外的已选条目数量会明确显示。统一权重须符合所有已选条目的范围。主列表批量删除后可在 10 秒内撤销，恢复原位置并保留剩余条目的后续修改和新增项。编辑器中删除或改权重仍需点击「保存修改」写回保存项；收藏操作直接更新共享的「我的收藏」。

**LoRA 排序、筛选和标签**：列表操作区下方可按名称、权重、启用状态、收藏或标签排序，也可按关键词（匹配模型名及标签）、标签和启用状态筛选。筛选只改变显示范围；排序同步改变并保存实际 LoRA 加载顺序，拖拽会切回手动顺序。排序和筛选偏好随节点工作流保存，保存列表及 JSON 预设会记录排序方式。每行名称下方的「＋标签」支持多个自定义标签，多选工具栏的「标签」可批量添加或移除而保留其他分类。「标签管理」可创建、重命名和删除标签；重命名会更新关联模型。「添加 LoRA」选择器显示标签，支持标签筛选、排序和「同标签加入」（跳过已添加的模型），选择器偏好也随工作流保存。共享分类记录存储在 `ComfyUI/user/allbuy_promptlibrary/lora_catalog.json`，自动保留 `.backup`；跨节点和保存列表共享，备份插件用户数据时需同时保留此文件。

## 通用面板特性

- **执行锁定**：队列执行期间面板只读并显示状态条，可手动解锁；
- **旁路同步**：节点静音/旁路（Ctrl+M）时面板同步变暗标注；
- **调色隔离**：右键调色只影响节点框，不染内部 UI；
- **高度自适应**：面板随节点拖高填充、拖矮钳回内容下限；
- **版本握手**：footer 显示版本号，前后端版本不一致时控制台与 footer 提示（后端改完记得重启）。
