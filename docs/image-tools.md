# AllBuy 图像工具（v3.147）

重启 ComfyUI 并强制刷新浏览器，在 `AllBuy/图像工具` 搜索「图层合成器」「多图拼接」「图片标题」「生成」。功能设计参考 [NO8D controls](https://github.com/no8d/ComfyUI-NO8D-controls)，使用独立实现的 AllBuy 靛紫玻璃面板；不需要安装 NO8D 插件。

## 图层合成器

点击「打开图层工作台」，在左侧画布编辑，右侧管理画布尺寸、图层顺序与所选图层的属性。点击「＋ 导入图片」、拖入图片，或在非输入区粘贴图片都可添加素材。

- 工作台右下角内的「窗口大小」滑条调整工作台大小；旁边「界面字号」提供 16 / 18 / 20 / 22 / 24 / 28 / 32 px，默认 20 px，并记住本机选择。工具按钮、关闭按钮、缩放标签及底栏使用比所选字号大 2 px 的文字（至少 20 px），控件同时加大。工具栏「画布缩放」调节预览倍率，滚轮也可缩放，「适应画布」重置视图。
- 画布提供 1:1、4:3、3:4、3:2、2:3、16:9、9:16、4:5、5:4、21:9；1K / 2K / 3K / 4K 分别以长边 1024 / 2048 / 3072 / 4096 px 计算，短边对齐 8 px。可手动输入宽高；改变画布尺寸不会缩放图层。
- 图层列表可上下拖动排序，主题色横线提示放置位置，上方图层在前；锁定图层需先解锁才能拖动。仍可使用「上移 / 下移」按钮。长文件名自动省略，不再撑出横向滚动条。
- 鼠标悬停或键盘聚焦「自动抠图（RMBG）」按钮时，弹出依赖及首次模型下载说明；处理期间显示进度提示并锁定属性区，失败时显示具体原因。
- 节点拉高后，输出预览利用剩余高度，底部不再留一块无功能的空白。滑条和滚动条均使用 AllBuy 主题色。
- 尺寸、图层数量、操作说明和预览状态显示在节点顶部输出接口左侧的空白区，下方面板保留合成预览和工作台入口。

- 点击图层选择，Shift 点击多选；在空白处拖框选择中心位于框内的图层。拖动移动；拖右下角方块等比缩放。右侧输入框可精确调整 X/Y、宽高、旋转与不透明度。
- 滚轮缩放视图，空格加拖动平移，「适应画布」恢复视图。超出画布的内容会在输出时裁切。
- 右侧图层列表上方代表前景，支持显隐、锁定、上下移动、复制和删除。正常、正片叠底、滤色、叠加四种混合模式可与透明度配合使用。
- 「橡皮擦」擦除当前图层的像素，保留原素材，擦除后的版本另存并可撤销。描边支持宽度及颜色。
- 在画布获得焦点时，方向键移动 1px，Shift 加方向键移动 10px；V 切换显隐，Ctrl+L 切换锁定，Delete 删除未锁定层，Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 撤销重做。编辑器保留最近 30 步布局快照。
- 「自动抠图」为可选功能：需要在 **ComfyUI 的 Python 环境**安装 `rembg`，首次使用可能下载 U2Net 模型。其余功能无需此依赖。

点击「保存布局」才写入节点并立即更新节点内的合成预览，无需先运行工作流；重新打开工作流也会根据已保存的布局和素材恢复预览。随后保存 ComfyUI 工作流。运行节点输出 RGB 图片、宽度和高度，并用实际输出更新预览。素材保存在 `input/allbuy_media/`，工作流保存布局与素材引用；跨电脑分享时需同时复制对应素材文件。预览描边使用轻量近似绘制，最终像素以运行结果为准。

## 多图拼接

`image_1` 为必接输入，`image_2` 至 `image_12` 可选，每路可接 IMAGE 批次。先按端口编号、再按每路批次顺序排列。

- 横向、纵向、网格；网格列数 0 自动选择。
- 以第一张图片的比例建立单元格；「单格最长边」0 使用首图原尺寸，也可设置统一尺寸。
- 适应保留全图，居左/居中/居右裁切填满单元格，拉伸填满但改变比例。
- 图片间距与外边距独立设置，背景色填充留白。
- 标题和预览位于节点上方输入接口右侧，下方参数面板独立滚动。预览保留完整拼图，按图片宽高比自动调整显示高度，并在可用空间内等比适应；横长图、竖长图都不会被裁切。

输出一张拼图，最多包含 256 张图片，结果画布最多约 3200 万像素。预览在执行后更新，执行命中缓存时也会重发并恢复预览；更新后需重启 ComfyUI 并刷新页面，使后端修复生效。

## 图片标题

输出预览填满节点上方输入接口右侧的可用区域，按实际接口标签宽度靠左扩展，并显示足够的标题周围画面来填充预览窗。根据本次执行的标题位置自动聚焦顶部、中部或底部，支持批次翻页。下方参数面板独立滚动，调节参数时预览保持可见；输出图片仍保留完整画面。

执行命中缓存时也会恢复预览。更新此功能后需重启 ComfyUI，再按 Ctrl+F5 刷新页面，使后端的中间节点预览重发标记生效。

单行标题应用到整个批次，多行标题按图片序号对应；缺少的行和空行不绘制文字。图内顶部、图内底部、中部保持图片尺寸，图外顶部/底部增加高度。为保证 IMAGE 批次尺寸一致，图外模式的空标题也保留同高背景栏。

「标题文本」右侧的「序号」可选择关闭、递增数字或大写字母，默认关闭。例如标题「旗袍」生成「旗袍1、旗袍2…」或「旗袍A、旗袍B…」，字母超过 Z 后继续 AA、AB…。序号按全部输入口与批次的总顺序递增，多行标题也支持；空行仍不绘制标题，但占用对应的图片序号。

`images` 为必接输入，`image_2` 至 `image_12` 可选，每路均可连接单张图片或 IMAGE 批次。按输入口编号、每路批次顺序处理，多行标题按所有输入的总序号对应，输出包含全部结果的 IMAGE 批次，可直接连接「保存图像」批量保存。不同尺寸按首图画布等比适应并居中，留白使用标题底色；最长边可保留首图原始尺寸，或缩放为 1K / 2K / 4K。

- **字体**：下拉选择系统字体或插件根目录 `fonts/` 下的 `.ttf`、`.ttc`、`.otf`、`.otc` 文件，选项为字体文件名。添加字体后重启 ComfyUI 并刷新网页。「自动（中文优先）」优先使用 Windows 微软雅黑、Noto CJK 或 macOS 苹方；Linux 若无中文字体应安装 Noto CJK。跨电脑分享工作流时需安装相同字体，或改选自动字体。
- **文字**：字号、颜色、对齐、左右留白；描边宽度和颜色独立设置，宽度 0 关闭。阴影支持颜色、不透明度、水平/垂直偏移和模糊，不透明度 0 关闭。标题过长或栏过矮时，文字及其描边、阴影一起缩小以适应。
- **标题栏**：高度为图片高度的百分比，底色不透明度 0–100%，圆角以像素设置，0 为直角，最大有效半径自动限制为标题栏短边的一半。圆角大于 0 时，同一行显示「标题栏宽度 %」，默认 100%，缩小时标题栏水平居中，文字在栏内对齐并自动适应；圆角为 0 时隐藏宽度并使用满宽。图内圆角露出原图；图外标题栏以黑色衬底输出圆角及透明度效果（IMAGE 为 RGB），空标题也保留相同样式的标题栏。
- **数值拖动**：所有数值框及其标签均支持按住左键左右拖动，向右增加、向左减少；Shift 加速、Alt 精调。也支持直接输入和键盘上下键，拖动自动遵守数值上下限。图层合成、拼接、生成面板共用此交互。

## 生成

连接 `model`、`positive`、`vae`。普通文生图再连接 `latent`；可选 `negative`，未连接时由原生 ConditioningZeroOut 生成零负向条件。节点使用 ComfyUI 原生采样器、调度器、VAE 编解码，右侧从上到下输出「原图」「图片」「Latent」。

「原图」为最后导入并按导入尺寸设置缩放后的图片，不含遮罩，也不会被后续局部重绘、扩图或「普通生成」覆盖。可连接到参考图编码等上游节点，无需等待本节点采样。先导入图片后再使用此接口；旧工作流的「图片」「Latent」连线会自动迁移到对应输出。

- **普通生成的 Latent**：接入 `latent` 时优先保留上游采样数据、尺寸和批次数，包括经切换节点传来的自定义分辨率。底图可以继续供 Qwen 参考编码使用，不再覆盖该 Latent。加载图像附带的空遮罩不会改变此优先级。
- **图生图**：未接入 Latent 时，连接 `source_image` 并调整降噪强度，底图经 VAE 编码后采样。连接有效遮罩或启用编辑器保存画布时，仍按重绘画布编码、合成。
- **导入 / 拖入底图**：点击「导入底图」，或将图片文件拖到预览区、参数面板及节点上，亦可在面板粘贴图片。导入成功后立即预览并启用图生图，无需先运行；点击「局部重绘 / 扩图」再涂抹遮罩。重新导入会清除旧遮罩。
- 导入前可设置「导入缩放」与「目标尺寸 px」：默认原始尺寸，也可按最长边或最短边等比缩放到指定像素，支持缩小和放大。按钮导入、拖放与粘贴共用此设置，并随工作流保存。例如 1600 × 1200 的图片，最长边 1024 得到 1024 × 768，最短边 1024 得到 1365 × 1024。缩放在上传前完成，后续重绘使用缩放后的底图；最终尺寸仍需符合编辑画布上限。
- **Latent 比例**：「目标尺寸 px」旁的「比例」默认「跟随输入」，保留上游 Latent 尺寸。选择 1:1、4:3、3:4、16:9、9:16、3:2 或 2:3 后，以目标像素作为最长边 / 最短边设置普通生成的 Latent 画布；「原始尺寸」模式下按最长边计算。最终尺寸按 VAE 压缩倍率对齐，Qwen 参考模式再按 32 px 网格对齐。例如最长边 1536、16:9 得到 1536 × 864。此选项不裁切导入底图，也不改动已保存的重绘画布。
- **普通生成的底图缩放**：未使用上游 Latent 时，连接 `source_image` 的图片同样遵循最长边 / 最短边设置，在 VAE 编码前等比缩放，连接的遮罩同步适配尺寸。已导入、已保存的编辑画布不会再次缩放，避免改变涂好的遮罩和扩图范围。
- 降噪默认值统一为 1，导入 / 拖入底图及切回普通生成时也设为 1。需要保留更多底图内容时，可以手动调低。
- **连接遮罩重绘**：同时连接 `source_image` 与 `mask`，白色区域重绘，黑色区域保留。遮罩批次可为 1，或与图片批次数相同。
- 普通生成时，同一个原生「加载图像」节点附带的全黑空遮罩按未连接遮罩处理，直接输出整图生成结果。加载图像中涂好的非空遮罩、其他遮罩节点与编辑器保存的遮罩仍按黑色保留、白色重绘处理。
- **面板重绘**：生成或导入底图后点击「局部重绘 / 扩图」。在画布上涂抹遮罩，可擦除、清空、全选遮罩、撤销和重做。保存编辑后运行工作流。
- 保存后，节点里的底图预览也会叠加紫色半透明遮罩，标出已涂抹及扩图区域；恢复工作流时同样显示。切换历史图片、采样预览或最终结果时显示对应图片，避免旧遮罩覆盖结果。
- 重绘与扩图窗口沿用图层工作台的界面：默认 20 px 字号，支持 16 / 18 / 20 / 22 / 24 / 28 / 32 px，两个编辑器共用本机字号偏好；右下角提供窗口大小滑条，右侧参数区独立滚动。画笔直径可通过数值框或主题色滑条同步调整，当前涂抹 / 擦除模式会高亮显示。
- **扩图**：在编辑器设置上下左右新增像素，点击「应用扩图」。新增区域自动设为白色遮罩，原区域保留现有遮罩。保存后运行，建议降噪为 1.0。
- **恢复普通生成**：点击「普通生成」清除面板编辑状态，并将降噪恢复为 1，重新使用连接的输入；再次拖入图片会重新启用图生图。仍在上传的旧底图不会覆盖后续导入的新底图。
- 节点缩到最小高度时，参数仍在节点内部滚动，不会溢出节点边框。
- 导入 / 编辑底图生成的历史只保留本次打开期间最新 4 张预览；普通生成更新预览并输出到下游，不新增历史缩略图。历史可选择为编辑来源，重新打开工作流时自动清空，不保存临时历史引用；已保存的底图与遮罩仍会恢复。
- 「普通生成」右侧的「清空」移除全部历史记录和历史预览，保留导入底图与遮罩，不删除图片文件；无历史时按钮禁用。历史缩略图保持 64 × 64 px，右下角「×」可移除单张；本次打开期间缓存重播不会重新加入已清除的记录。
- 「运行生成」固定在输入接口旁、图片预览上方的空白区，参数滚动时保持可见；不遮挡输入 / 输出接口。接口区高度不足时显示在参数区上方。
- 生成节点默认面板高度从 660 px 缩短为 540 px，已有工作流保留保存的尺寸，可手动缩小。
- 采样时显示 ComfyUI 发送的实时预览，完成后替换为最终图片；需在 ComfyUI 启用预览方式。未启用实时预览时保留底图或上次结果，直到生成完成。命中缓存时也会恢复最终预览，载入工作流时优先显示已保存的编辑底图。

面板编辑启用时，已保存的底图和遮罩优先于输入图片/遮罩。羽化在编码及最后像素合成时使用；VAE 编码前会按其压缩倍率对齐画布尺寸。编辑器最多约 1600 万像素、边长 8192；遮罩历史根据像素总量限制内存。图像输出包含最后的遮罩合成，Latent 输出为采样器结果。

底图、遮罩和 Latent 按需读取：使用导入 / 已保存底图时，不执行这些输入口上闲置的上游分支；普通生成接入 Latent 时读取该分支，有遮罩时先判断是否为加载图像附带的空遮罩，再决定是否使用底图重绘。节点内「运行生成」提交本节点及相连的下游输出节点，包括预览、保存、图像对比和经过中间处理连接的输出，使结果继续输出到这些节点；不带跑无关的其他输出分支。ComfyUI 全局运行仍按整张工作流执行。模型、正负向条件和 VAE 的必要上游照常运行。图片导入完成、预览更新后才能点击「运行生成」。更新输入调度后需重启 ComfyUI 并强制刷新页面。

正负向条件直接连接原生 `TextEncodeQwenImage21` 时，导入 / 保存底图后，入队会为当前生成复制参考图编码节点，将第一张参考图同步为本次导入的图片，额外参考图和原工作流连线保留。参考编码使用导入后的尺寸，并与采样底图统一按 Qwen 的 32 px 网格取整。这样降噪为 1 时也能通过 Qwen 参考图条件使用导入图，而不是继续使用旧的参考图。

普通生成选择最长边 / 最短边时，同样会为当前生成复制 Qwen 参考编码，将第一张参考图按设置缩放，并关闭编码器额外的尺寸缩放。仅未接 Latent 或直接使用该 Qwen 编码器自身的自动 Latent 时，同步对应尺寸；外部自定义 Latent 与切换节点连线保留。比例为「跟随输入」时以其尺寸为准，显式选择比例后再调整采样画布。其他分支、原编码器和额外参考图不变。

这是通用的原生采样和重绘流程，未加入 NO8D 对 Flux2 Klein / Krea2 Identity Edit 的专用参考图编码分支。需要此类模型专用条件时，应在上游使用相应模型节点准备条件；不能将本节点视为这些专用编辑链路的完整替代。

## 验证

`python -m pytest tests/ -q` 检查现有功能回归、新增像素处理与模拟原生采样接口。`python tests/browser_image_tools.py` 在模拟 ComfyUI 宿主中检查真实浏览器控件、导入、保存、遮罩和扩图操作，并生成截图；此脚本需要 Playwright 和 Chromium，可以通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定已有浏览器。

上述自动检查不等同于在实际 ComfyUI 中加载模型出图。首次使用仍需在你的模型工作流中验证采样与显存表现。
