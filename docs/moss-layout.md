# MOSS 布局工作台

节点名：**AllBuy-布局提示词（MOSS）**，分类：`AllBuy/图像工具`，独立标识：`AllBuyMossLayoutPrompt`。可与 ComfyUI 原生及其他 MOSS 节点并存，无新增 Python 或前端依赖。

## 编辑与连线

1. 打开工作台，填写整体场景；添加物体、角色和文字，或选择海报 / 封面示例。
2. 在画布上拖动元素、拖八个控制点缩放，或在右侧输入像素 / 百分比坐标。点「画框」可创建物体框；双击元素可聚焦对应的描述或文字字段。
3. 元素列表按从后到前排列，可前移、后移、复制或删除。重叠时通过编号标签选中指定元素，或重复点击交叠处循环选择。
4. 在右侧顶部「MOSS 分辨率」选择像素档位与画布比例，即可自动计算尺寸并预览。手动填写宽高后点「应用尺寸」。勾选「按比例缩放元素」会同时调整方框；取消勾选保留原坐标，越界时需要修正后才能保存。宽高须为 16–4096 的 16 的整数倍。
5. 点击「保存并应用」，再保存 ComfyUI 工作流。编辑本身不会启动生成。

| 输出 | 连接方式 |
|---|---|
| 提示词 STRING | MOSS 正向 `CLIPTextEncode` 的文本输入，必要时先把文本控件转换为输入口 |
| 宽度 / 高度 INT | MOSS 工作流对应 Latent 的尺寸，例如 `EmptyFlux2LatentImage` |
| 布局草稿 STRING | 标准草稿，包含画布尺寸和左上角像素坐标，可重新导入 |

节点不加载模型，不改变已有 MOSS 工作流的采样与模型设置。布局对模型的约束效果取决于 MOSS 模型；其他模型没有保证。

## 外部分辨率与 MP

节点新增可选 `width` / `height` 两个 INT 输入，界面显示「宽度」「高度」。接入分辨率节点的对应输出后，已接入的轴优先覆盖工作台和草稿尺寸，未接入的轴沿用草稿尺寸。布局框按相对位置缩放，编译提示词、输出尺寸与布局草稿使用同一个最终画布。

任一尺寸输入接线后，工作台尺寸区显示「外部分辨率优先」，内部尺寸控制项只读；断开连线后可继续手动设置。常规整数或带同名尺寸控件的上游节点可即时预览；动态计算且无法提前读取的输出会提示等待上游执行，运行后同步实际尺寸，并标明上次执行值。预览不会静默改写保存的布局，点击「保存并应用」才会保存当前草稿。

像素档位与计算方法来自 [OpenMOSS 官方预设](https://github.com/OpenMOSS/MOSS-Image/blob/6be4453024c5acae9dcd0a191e26ee524e743310/gradio_presets.py)：默认提供推荐的 1M、1.5M、2M，以及 0.25M 轻量和 4M 扩展档位，宽高分别四舍五入到 16 的倍数。支持方形、4:3、3:4、3:2、2:3、16:9、9:16 等常用比例；旧草稿和手动尺寸仍可使用。

界面中的 **MP 为实际百万像素**（宽 × 高 ÷ 1,000,000）。M 档位沿用官方预算：1M 档为 1,048,576 像素，所以 1024 × 1024 显示 1.05 MP，1536 × 1024 显示 1.57 MP。推荐与扩展范围见 [官方指南](https://github.com/OpenMOSS/MOSS-Image/blob/6be4453024c5acae9dcd0a191e26ee524e743310/USERGUIDE.md)。

画布纸面、网格和文字颜色随深浅主题切换。两种主题均显示 16 px 基础格线与每 64 px 的加深主格线，便于定位；仅影响编辑预览，不会给模型提示词添加网格。

## 保存与恢复

工作台中的修改保留为当前节点的恢复草稿，正式执行始终使用最近一次「保存并应用」的布局。关闭未应用编辑时会提示，再次打开可选择「恢复草稿」。草稿和参考图引用属于各自节点，不会覆盖其他布局节点。保存工作流后，这些数据一起保留。

参考底图通过 AllBuy 本地素材接口保存，节点只存文件引用。显示开关和不透明度不影响提示词。标准草稿导出不包含底图，迁移工作流到另一台机器时需要单独迁移素材或重新载入。

## 导入、导出与编译

「导入布局」支持标准 `abs/xyxy` 草稿、`abs_centralized/yxyx` 编译提示词和旧版 `scene_type/gen_brief/elements`。可粘贴带代码围栏或说明文字的 JSON，亦可选择本地文件；外层 `layout/draft/source` 包装会被识别。不会执行粘贴内容中的代码。

编译后的提示词没有画布宽高，导入前须设置它原来的尺寸。超出当前画布的坐标会报错，不会自动改动构图或清空当前布局。标准草稿自带尺寸，适合无损往返编辑。预览、导入与节点执行共用 Python 编译函数：按官方规则取像素包围边界并转换成画布中心的 `yxyx` 坐标。

没有布局元素时，节点输出整体场景的普通文本。文字元素的文字不能为空；格式、空文字和坐标错误会在工作台显示，禁用应用按钮。最多 200 个元素，导入内容上限 2 MB。

## 快捷操作

- 空格 + 拖动或鼠标中键：平移；滚轮及「＋ / －」：缩放；「适应」：恢复居中。
- 方向键：移动选中元素 1 像素；Shift + 方向键：16 像素。
- Delete / Backspace：删除选中元素，文本输入期间保留正常编辑行为。
- Ctrl / Command + Z：撤销；Ctrl / Command + Shift + Z：重做。
- Esc：关闭工作台；Tab 在工作台控件内移动焦点。

界面复用 AllBuy 的深浅主题、字号和窗口大小设置。来源与许可证见 [third_party/moss-layout/NOTICE.md](../third_party/moss-layout/NOTICE.md)。

外部节点的缩略预览按布局画布比例显示，预览高度限制在 160–480 px。节点高度根据预览、说明和状态文字自动计算；改变节点宽度、切换横竖画布或恢复旧工作流后会重新适配，底部不保留固定高度的空白。
