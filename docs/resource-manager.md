# 资源管理指南

点击画布右下角「资源管理」打开面板。勾选资源后可批量整理，或点「添加到工作流」。面板会记住当前浏览器中的搜索、分类、排序和滚动位置。

## LoRA 分组、标签与组合

- **分组**用于整理模型；标签可交叉分类。标签编辑支持搜索、批量关联、新建和取消修改。
- **堆栈**编辑当前工作流节点；修改先保留为草稿，点击「应用到节点」后还需保存工作流。
- **组合**保存 LoRA 的权重、顺序、启停与激活词，可导入导出分享。
- **推荐权重**支持单一数值或区间。模型详情中的「应用权重」只调整本次使用；「使用推荐」可恢复默认值。

节点内的堆栈分组还可折叠、整组移动与启停；停用组保留各条 LoRA 原来的独立开关。移动过的文件可通过「检查 / 找回文件」重新匹配，存在多个同名文件时需手动选择。

## Civitai 来源信息

在 LoRA 详情中点击「从 C 站拉取信息」，可按本机文件哈希匹配，或填写带 `modelVersionId` 的版本链接。预览结果后勾选需要的字段，再保存。

| 可获取 | 使用方式 |
|---|---|
| 底模与版本 | 补充模型说明，也可手动编辑或恢复自动读取 |
| 激活提示词与作者说明 | 查看使用要求，按需保存 |
| 内容评级 | 用于正常显示、模糊或隐藏预览 |
| 推荐权重与区间 | 来源有明确建议时才导入，仍可手动调整 |

分类标签由用户自行管理，不导入 C 站标签。默认保留手动填写的信息；推荐权重需单独勾选。只发送模型哈希，不上传模型文件，此入口不下载预览素材。

### 批量获取

在 LoRA 页顶部选择「C 站批量获取」，可处理已勾选、当前筛选结果或全部可见模型，最多 5000 项。结果逐项保存，支持查看进度、搜索失败项和重试。关闭进度窗口后任务继续；停止任务会保留已保存的信息。

### 授权与网络

公开信息可直接读取。需要授权时，展开「API 授权」，在 [Civitai 账户设置](https://civitai.com/user/account)创建 API Key，填入后「验证并保存」。也可使用启动环境变量 `CIVITAI_API_KEY`。界面只显示配置状态，支持清除本地密钥。

连接失败时先点「测试连接」。请求由 ComfyUI 后端发出，可选择自动、直连或自定义 HTTP / 混合代理。代理设置仅影响 C 站请求；浏览器能访问 C 站不代表后端已经连通。

## 内容显示

LoRA 页「内容显示」可选正常显示、模糊预览或隐藏模型，并记住偏好。

- 模糊同时作用于卡片、详情和悬停预览；主动选择「临时显示」后才展示内容。
- 评级可读取本地来源信息或手动指定，手动设置优先；未评级内容可选择一并处理。
- 隐藏同时作用于搜索、收藏与分组，不会删除模型文件。刷新或重新打开面板会恢复保护状态。

## 筛选与重复检测

高级筛选支持底模多选、版本关键词、标签包含 / 排除，以及任一或全部标签匹配。可保存最多 30 个筛选预设，方便重复使用。

重复检测支持当前筛选结果或全部可见模型，先按文件大小找候选，再计算完整 SHA256。可取消任务，关闭窗口后也能返回查看结果。结果只提供定位与复制路径，不自动删除文件。

## 工作流整理

- 按文件夹、标签和收藏浏览，双击工作流打开。
- 左侧目录区域长按约 0.3 秒后拖动框选，Ctrl / Shift 可追加选择，Esc 取消。
- 可对工作流或文件夹使用「保存并关闭页签」；保存失败会保留页签并停止后续操作。
- 移动工作流时可选择先保存关闭再移动；删除后的工作流可在回收站查看。

浏览位置和筛选偏好保存在当前浏览器。提示词库、LoRA 信息、工作流和素材的备份位置见 [README](../README.md#backup)。
